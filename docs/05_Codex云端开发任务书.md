# Codex 云端开发约束

2026-10-31 正式需求变更取代早期分阶段任务中强制人工审批和业务内容脱敏的要求。

先阅读 AGENTS.md、README、PLAN、产品架构、协议和测试规格。以当前源码为准，拉取最新 main，检查工作树，独立分支，先列实际影响再编码，不覆盖其他任务。

保留唯一 daemon、STDIO 薄桥、官方 SDK、固定七工具、串行/互斥图、不可变发布、环境绑定、Schema、引用与参数校验、凭据库、secretRef、管理认证和宿主 owner。

不创建审批节点、决定接口、审批开关或替代确认流程；业务输入、输出、报告及证据不自动替换内容。凭据保护仅用于连接管理与内部认证诊断。

旧数据库保留。迁移需一致性备份，复制新的无审批草稿，不改变已发布快照；活跃旧运行停止且明确记录原因。无法安全转换的工作流返回具体错误，不猜测业务分支。

测试只使用合成 MCP 和数据。修改引擎、绑定、凭据、状态或存储时补充正负向测试。运行 check、test、build、UI、平台离线包与冒烟。Windows 原生 CI 另行验证。未执行、失败或受阻如实记录，不以编译替代验收。

不自动发布、推送、合并，不连接企业系统，不索要企业凭据。
