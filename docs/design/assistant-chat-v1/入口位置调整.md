# 悬浮助手入口位置调整

2026-10-31，增量基线为 `3b91849`。用户要求图标支持移动并贴边隐藏，保持原聊天会话和工具执行行为。

## 使用与实现

- 按住图标或已收起的边缘标签拖动，鼠标和触屏均支持；松手吸附到较近的左右边缘，保持选择的高度。
- 图标旁箭头贴边收起，仅露出22px标签；标签上半部分打开聊天，下半部分恢复完整图标。聊天窗口跟随左右位置。
- 位置、左右边缘及收起状态写入当前浏览器的 `flowhub.assistant.launcher.v1` 偏好，只存布局数据；刷新和切页保留。非法偏好回退默认值，存储不可用时仍可操作。
- 键盘方向键调整位置，Esc贴边收起。视口或手机键盘改变可用区域时重新限位，入口不会永久移出可视范围。
- Pointer Capture保持跨区域拖动；移动阈值区分点击和拖动，拖动结束不会误发一次打开事件；pointercancel恢复原位置。拖动不取消任务、不新建会话、不请求模型。
- 新增 `AssistantLauncher.tsx`，复用原 `FloatingAssistant`；没有依赖、迁移或数据重建。

## 本机运行中发现并修复的故障

本机旧daemon PID91311在事件流缓冲过大时，关闭响应后心跳仍写入，产生 `ERR_STREAM_WRITE_AFTER_END` 并退出。已用临时daemon及2MiB合成事件稳定复现，保留失败日志；修复为幂等关闭、响应可写性检查、关闭/错误时清理定时器、发送失败后不再发送心跳，也不再启动已关闭流的定时器。

新增真实HTTP回归覆盖积压关闭后的多个心跳及客户端主动断开；已有退出、会话注销、过期用例继续保留。仅确认记录PID已退出后移除陈旧锁，数据库通过只读quick_check后正常启动；不删除数据库或令牌。新daemon备份preflight通过，24张原表内容hash一致；实际HTTP返回与当前Web构建一致，事件连接断开后健康检查正常。
