## D1 / D3 后端

- 发现器用正式 YAML 解析 Skill 介绍及 MCP 依赖；读取插件介绍。插件包含、工具所属服务、结构化声明依赖及说明中提及分别记录。
- 新增第3号顺序迁移，增加 `discovery_entities` 与 `discovery_presentations`；v1/v2 DDL/checksum不变。
- 完成扫描后事务更新目录投影，分页、统计与详情使用同一完成快照；部分扫描中未确认的旧来源移到需处理，保留旧资料。
- `host_scan` 兼容旧扫描参数，新增 `action=submit_descriptions`，固定工具仍为21个。Web手工编辑复用相同显示层服务。
- 中文提交有来源/上下文/CAS/owner/幂等/批大小/Schema指针/证据引用校验，失败批次事务回滚；保护手工文案并标记过期译文。执行身份和Schema不因翻译而改变。
- 宿主目录的工具保留已确认服务归属；元数据刷新不丢归属，父服务禁用或漂移后旧宿主工具不可导入。
- 增加真实管理API；生成OpenAPI。更新解析依赖基线，安装后审计0漏洞。

已执行：`npm run build:server`、原发现/迁移33项测试、新增7项显示层测试；随后包含新迁移恢复与MCP闭环的21项针对性测试通过。完整测试与最终计数在D4结束后补齐，不累加重复执行数。
