# 架构决策与风险

2026-10-31 更新。

| 决策 | 原因与边界 |
|---|---|
| 单个 MCP Server、固定七工具 | 新工作流增加数据，不增加宿主工具 |
| Codex 推理、Hub 执行 | 使用宿主 Agent/Skill，无额外模型 API 依赖 |
| 唯一 daemon 与 STDIO 薄桥 | 避免双引擎和 SQLite 重复写入 |
| 不可变发布与运行快照 | 草稿变化不改变既有运行；迁移只能新建副本 |
| 保留环境与资源绑定 | 删除审批不能让 Agent 覆盖连接、环境、模板或工具白名单 |
| 工具直接执行 | 满足发布、绑定、Schema 和参数要求后执行，不等待人工决定 |
| 业务内容原值存储 | 排障、映射、报告和证据一致；不提供业务脱敏规则或开关 |
| 连接凭据继续加密 | secretRef 与 token-file 引用，列表和认证诊断不泄露内部凭据 |
| MD/HTML 及证据校验 | 核验真实字节、哈希与归属，不把宿主声明当作已验证事实 |
| 串行与互斥分支 | 保留预算、取消与明确的不确定结果，不承诺跨系统 exactly-once |
| 旧数据备份与副本迁移 | 原始数据库、已发布版本、运行和报告保留；不自动重放旧调用 |

风险：业务数据现在完整保存，按既有生命周期清理，备份仍含完整状态。旧报告中已经丢失的原值无法还原。第三方 MCP 的实际权限需独立验证。Windows、真实 Codex 和企业服务仍需原生/本机验收。结果不确定的调用不重复执行。历史资料只说明当时结果，不能替代本次验证。
