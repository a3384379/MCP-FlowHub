## 2. 一致性修正

本轮已对齐固定七工具、DSL目标JSON Pointer映射、输入question/orderNo/from/to、默认发布版本指针、标签长度、无隐式业务默认值、串行/互斥分支、OUTCOME_UNKNOWN终态和报告实际内容验证。

已补充两个恢复语义：Skill不可用且未选择预声明降级时不消费检查点；checkpoint使用hash校验及受vault保护的加密交付副本，避免“只存hash却试图重启还原token”的矛盾。幂等响应不得明文保存token。

原型额外修正：并行节点标V1.1禁用、环境明确MOCK_VERIFIED、人工批准后的进度、拒绝与取消分开、交接字段名与契约一致、列表/编辑器的演示版本展示一致。

## 3. 尚未完成、不能宣称通过的验证

1. **完整JSON Schema Draft 2020-12标准验证器/元Schema验证**：当前仅有自定义子集检查。实施CI必须引入锁定版本AJV等标准验证器并增加兼容测试。
2. **Mermaid渲染器验证**：提供10张图的代码与提取文件，已人工检查关系和基本语法，但本次未运行独立Mermaid渲染器；GitHub/支持Mermaid的阅读器可用于后续查看。
3. **Hub实际实现**：尚无真实状态机、SQLite事务、CAS、OAuth、secret vault、MCP运行时或安装包。
4. **100项产品验收**：它们是详细待执行用例，与本次103项设计静态检查不是同一组测试。
5. **真实Codex闭环**：原型模拟了Agent回传，不证明实际宿主已兼容；阶段S4需要真实宿主冒烟。
6. **企业环境**：没有接触公司MCP、私网、数据库、日志、凭证或加密软件；公司授权与离线PoC仍是阶段门禁。
7. **UI完整交互**：自由拖拽/连线/撤销、持久化、所有弹窗路径、移动端真机和正式无障碍指标未作完整验收。
8. **安全认证**：没有做完整渗透测试、组织合规认证或证明能够隔离已控制同一OS账户的Agent。

因此本次可以交付的是“可直接转为开发任务的完整设计与原型”，不是“已经可投入生产的问题排查工具”。
