# 分组直达导航实施与验收

2026-11-01；基线 `29d3c0dafa9d2eecea7dfed26d3ca1d058235403`；分支 `feat/flowhub-v2`；Node 24.19.0 / npm 11.9.0 / macOS arm64。按用户选中的“分组直达（推荐）”方案增量修改现有仓库。

## 实际修改

- 三组七个同级入口：工作区（工作流、运行记录）；能力与连接（能力发现、MCP 服务、环境与资源）；系统配置（模型设置、系统设置）。模型保持一步直达。编排与 AI 工作台未恢复为一级入口。
- 导航配置抽到 `features/navigation/navigation.ts`，侧栏与移动抽屉抽到 `AppSidebar.tsx`。所有入口使用同一组本地线性 SVG 图标，无网络字体、图标 CDN 或新依赖。统一行高、左对齐、选中与键盘焦点样式，取消缺失图标形成的假层级。
- 常驻侧栏宽 228px；本机工作空间缩为品牌下方一行；底部保留账户与退出操作，移除侧栏 Gateway 大卡片和无真实进度语义的横条，固定 21 工具及宿主接入说明仍在系统设置页。
- 面包屑、浏览器标题、助手的当前页面名称复用导航名称；同步连接表单、发现详情、能力选择器中的跳转说明及当前使用指南。API 路径与原 `/tools`、`/editor`、`/assistant` 兼容行为保留。
- 不超过 760px 时，顶部按钮打开导航抽屉。抽屉通过 Portal 显示，背景 inert 并锁定页面滚动，初始聚焦关闭按钮，Tab/Shift+Tab 循环，支持 Esc/遮罩/关闭按钮，关闭时恢复焦点和原状态。选中路由、浏览器后退或回到桌面断点后关闭抽屉。
- 保留原脏状态判断；取消离开不关闭导航、不丢弃编辑；接受离开后正常路由跳转。没有新增认证流程、数据表、模型请求、业务 MCP 调用或自动扫描。
