## 独立协议和完整链路

SDK server/client 2.4.0、Node adapter 2.1.2。modern 2026-07-28、legacy 2025-11-25，Hub 与 Mock 的 STDIO/HTTP 各有独立协议测试；公开表面严格七工具。中文、emoji、错误输入、额外字段、固定环境覆盖均有真实协议断言。

production 与 staging 的完整链路均实际执行：

搜索/取契约 → 启动 → 日志 MCP → WAITING_AGENT → 结构化查询意图 → WAITING_APPROVAL → 独立管理会话批准 → 数据库 MCP → 环境专用哨兵 → Agent 汇总 → 报告内容/模板 → Markdown/HTML → SUCCEEDED。

哨兵 PROD_ONLY_SENTINEL_017 / STAGE_ONLY_SENTINEL_029 互不混用。没有企业网络、账号、日志或真实订单。

已验证的关键负例：并行/环/跨分支引用/漂移哈希/未知代码节点拒绝发布；相同键同结果、不同内容冲突、并发仅一次推进；Agent 不能更改订单/凭据/环境或批准；陈旧/拒绝审批不派发 DB；外部登记的 Mock 也只能 MOCK_VERIFIED；401/403 不降级；污染 STDIO 连接被拒、缓存修订/SDK 失效；检查点只存 hash 和 AES-GCM 交付副本，重启锁定、解锁可恢复；未确认 dispatch 保留 OUTCOME_UNKNOWN，不自动重放。

## 外部验收和保守限制

Windows 原生构建/离线运行、Windows ACL、公司文件加密与授权目录、真实 Codex/私有 Skill、企业生产/试运行只读权限均未在本环境执行。CI 代码已提供但没有本次 GitHub CI 运行链接。不能用 Linux/Mock/独立 SDK 客户端替代这些证据，也不声称正式生产可用。

完整设计的某些人工/故障组合没有逐项执行：100 节点画布压力、完整键盘/可访问性、磁盘满/真实进程崩溃窗口、全链路重试/预算故障矩阵、升级跨版本兼容和所有 legacy 版本。没有将未执行项填 PASS。

实现采取保守策略：没有可信未派发/安全重试依据时停止，不自动重放不确定操作；不实现任意 SQL/JS/文件节点、循环并行、多租户、旧 HTTP+SSE 自动 OAuth 或自动更新。真实服务需符合标准化环境/输出契约，否则应在获准环境配置受审查适配器，不静默硬编码企业字段。

结论：可审阅、可运行的 **1.0.0-rc.1 云端候选实现**，主要合成开发链路通过。正式发布仍受外部验收和独立安全/许可审查约束；尚不能宣称所有 100 项验收或企业部署已完成。
