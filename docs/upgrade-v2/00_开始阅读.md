# MCP FlowHub 2.0｜本地 Codex 开发设计包

**版本：2.0-design.1｜日期：2026-10-31｜核查基线：main@45eed03**

本包服务于现有 MCP-FlowHub 仓库的增量升级，不包含已实现的 2.0 产品代码或安装包。

## 最快开始

1. 将整个文件夹放到当前仓库的 `docs/upgrade-v2/`，保留已有 `AGENTS.md` 和其他文档。
2. 阅读 [基线与产品边界](docs/01_基线核查与产品边界.md)；确认本地最新主干是否有后续变更。
3. 将 [本地 Codex 升级提示词](docs/05_本地Codex升级提示词.md) 的“总提示词”复制给本地 Codex。
4. 按 S0–S7 分阶段实施与本地提交。验收对照 [测试方案](docs/04_测试与验收方案.md)，不以聊天说明或编译成功代替真实结果。

## 本次确定的三条主线

**自动发现 Codex 能力 → Codex 通过 MCP 自主编排 → BYOK 网页助手问答及改图。**

保留单一 MCP Server；原七运行工具兼容，新增十四固定工具；没有Key仍可通过Codex使用。不会重新加入人工审批或业务自动脱敏。

两个特别重要的实现点：插件目录不等于独立可调用工具；SQLite旧版迁移校验和必须冻结后再加表。开发文档已给出具体处理方式。

## 检查边界

本次核查了目标仓库部分关键源码、目录与当前CI状态，并查阅官方接口资料；没有对当前产品执行新一轮全量测试，也没有访问本机Codex或公司MCP。包内所有2.0验收项初始状态均为未执行。

离线原型不读取任何本机文件、不调用模型或MCP、不保存真实Key。双击HTML即可查看；它不是正式UI实现。
