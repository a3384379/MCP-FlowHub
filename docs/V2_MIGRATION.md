# 2.0 迁移与回滚

v1 DDL、表顺序及校验和冻结在 packages/persistence/src/v1.ts。
后续迁移只能追加，已知历史必须是完整前缀；缺表、列变化、checksum 错误与未来版本拒绝启动，不能清库或修正历史。
启动、备份预检与恢复共用同一只读历史校验。迁移 DDL 与历史插入在同一事务，失败回滚。

正式升级前停止旧 daemon/bridge，保存旧程序和一致性备份。开发测试不得指向正式数据目录。
回滚必须停止新程序并恢复匹配的旧备份与旧程序；禁止删除 schema_migrations 行伪装降级。
S1 的 migration 2 增加能力、编排账本、测试、模型、助手、知识及事件表与索引。启动旧库前先一致性备份；合成旧库的 checksum/快照字节保留与恢复负例已通过。完整离线回滚演练在 S7 记录。
